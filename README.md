# Sales & Revenue Analysis Dashboard

## Project Overview
An interactive Sales and Revenue Analysis Dashboard created using Microsoft Power BI to analyse sales performance and business trends.

## Tools Used
- Microsoft Power BI
- DAX
- Sample Superstore Dataset

## Dashboard Features
- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Sales Trend by Year
- Top 5 Products by Sales
- Sales by Category
- Sales by Region
- Interactive filters for Category, Region and Order Date

## Objective
To analyse sales data, track key performance indicators (KPIs), and identify business trends through interactive visualisations.

Data Analytics Internship Project
